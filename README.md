# Cave Aurora Edge

A premium creator, productivity and PC-control dashboard for the **CORSAIR XENEON EDGE**:
focus sessions, tasks, your own shortcuts, media, safe PC controls and system stats on one
2560×720 touch screen you arrange yourself. Made by
[Tom's Cave](https://marketplace.elgato.com/@tomscave) for iCUE 5.47 or later on Windows.

Get it from **Elgato Marketplace**, then install the free bridge below.

## Download the free bridge

**[CaveAuroraEdgeBridge-Setup.exe](https://github.com/Caveproduction-bot/cave-aurora-edge/releases/latest)**
from the Releases page.

The bridge is a small Windows program that powers the sound controls, media details, the
RAM and network readings, the notification count, your shortcuts and the PC controls. It
starts with Windows, talks only to your own PC, and sends nothing to the internet. Tasks,
work sessions, the clock, the countdown timer, colours and the CPU and GPU readings all
work without it.

Full setup steps: **[SETUP.md](SETUP.md)**

## Features

- **Your own shortcuts:** up to eight programs, folders or websites, four on screen at a
  time. Pick a program in a normal Windows file box, or paste a path or web address. Each
  tile shows the program's own icon and launches it with one tap.
- **PC controls:** Lock in one tap; Shut down and Restart need a press and hold until the
  ring fills, so a stray touch cannot end your session. Task Manager is one tap too.
- **Focus and tasks:** due dates, durations and priorities, suggestions from past tasks, a
  calendar of which days have work, and Undo on delete. Press play on a task to start its
  timer — the task's length becomes the goal — with pauses, timed breaks, a break reminder
  and a saved session for every stretch of work.
- **A countdown timer:** named, any length, snooze, and stored by its finishing time so it
  survives restarts, sleep and iCUE reloads.
- **Media and sound:** title, artist, app and artwork, a progress bar you can drag,
  previous / play-pause / next, a volume slider sized for a finger, and a switch between
  apps when two are playing. Mute, mic mute, Switch Sound and a picker for any output.
- **System:** live CPU, GPU, RAM and network along the bottom with history graphs. CPU and
  GPU work as soon as the widget is added, from iCUE's own sensors. Every reading has a
  source setting in iCUE, and a reading with no source says where to fix it.
- **Arrange it yourself:** tap LAYOUT and drag one panel onto another to swap them. Every
  panel keeps its own size wherever you put it.
- **Colours:** five backgrounds — Midnight Aurora, Ember Aurora, Total Eclipse, Violet
  Nebula and Graphite Slate — with any accent and text colour, set in iCUE's Widgets
  settings. Every combination is checked for readability before it is applied.
- **Also:** Movie Mode dims the whole dashboard, Show desktop, Windows notifications with a
  count, a display-mode button, and swiping between iCUE screens.
